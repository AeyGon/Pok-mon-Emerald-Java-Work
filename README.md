# 宝可梦绿宝石 Java 复刻 (Pokémon Emerald Java Clone)

这是一个基于纯 Java (Swing/AWT) 从零开始开发的 2D 像素 RPG 游戏项目。旨在学习和复现《宝可梦 绿宝石》等经典像素游戏的核心底层机制。

## 🗺️ 开发路线图与进度 (Roadmap)

本项目计划分为七个阶段稳步推进，当前状态如下：

- [x] **第一阶段：核心引擎与游戏循环** - 搭建 `JFrame` 游戏窗口面板。
  - 实现基于 `Runnable` 和 Delta Time 的 60FPS 游戏主循环 (Game Loop)。
  - 接入 `KeyListener` 实现流畅的 WASD 键盘移动控制。
- [x] **第二阶段：构建像素世界** (当前进度)
  - 引入 `Tile` 瓦片系统，成功加载并渲染外部图像素材（如草地、花朵）。
  - 实现 `TileManager` 地图管理器，支持读取 `.txt` 二维数字矩阵，并自动解析绘制出完整的游戏地图。
- [ ] **第三阶段：实体与物理交互** (碰撞检测与角色动画)
- [ ] **第四阶段：核心对象化设计** (宝可梦与技能数据类)
- [ ] **第五阶段：游戏状态管理与 UI** (文字框与菜单)
- [ ] **第六阶段：回合制战斗系统** (核心对战逻辑)
- [ ] **第七阶段：音效与细节打磨**

## 🛠️ 技术栈
* **语言**: Java (推荐 JDK 8 或更高版本)
* **图形库**: Java 原生 Swing / AWT (零第三方游戏引擎依赖)

## 🚀 如何运行
1. 将本仓库 Clone 到本地。
2. 使用 IDE (如 VS Code, IntelliJ IDEA, Eclipse) 打开项目。
3. 找到并运行 `src/main/Main.java` 即可启动游戏窗口，使用 WASD 控制方块移动。
